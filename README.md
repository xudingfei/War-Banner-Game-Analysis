基于 2026-09-13 的本机安装资源和脚本检查。正文区分已确认机制、解释性伪代码和未知部分。文件数量对应本机版本，不代表后续版本；伪代码不是原作源码，也不保证同种子复现原作地图。

陷阵之志与喵喵的结合的动画篇列出本机资源的具体动作帧数与名义时长，并解释状态选择、帧播放和效果调度的关系。素材帧数、SWF 时间轴帧数与屏幕渲染 FPS 分开讨论；本次没有进行实机逐帧录像或性能测试。帝国时代 IV 的具体动作帧数尚未可靠解码。

控制台篇结合程序字符串、局部反汇编和只读存档结构检查，区分命令历史、宏、回合快照、存档恢复与回放测试。没有开启调试开关或执行改变游戏状态的命令。

帝国时代 IV 篇结合本机 SGA 中的布局 Lua、参考属性 XML、骨骼动画资源与随附 SCAR 文档。参考属性不等于合并热更新后的最终对局数值；未进行批量地图生成或实机动画帧率测试。
